# 基于背景差分与 Otsu 阈值的表面缺陷分割

使用 Python、OpenCV 和 NumPy，将 200 × 200 灰度图分割为缺陷区域（白色）与背景（黑色）。程序包含对照算法、主算法、参数选择、批量评价和分步可视化。

本仓库包含 SD-saliency-900 的 900 对原图与标注。[实验结果](./results/batch_20261123_215924_544153/) 包含逐图指标、预测掩膜和分步案例。

## 运行

Windows 下在项目目录双击 `run.cmd`，或在 PowerShell 中执行以下命令。每次运行会在 `results` 下新建一个带时间戳的目录，保留已有结果。

```powershell
.\run.cmd
```

其他装有 Python 3.9 或更高版本的环境可以直接执行：

```console
python -m pip install -r requirements.txt
python run_project.py
```

程序默认从脚本旁的 `SD-saliency-900/Source Images` 读取 BMP，从 `SD-saliency-900/Ground truth` 读取同名 PNG。可用 `--data` 和 `--output` 指定其他数据根目录和输出父目录。单独处理一张新图时，可复用批量实验得到的参数，无需标注。例如，在项目目录运行：

```powershell
$batch = Get-ChildItem .\results -Directory -Filter 'batch_*' | Sort-Object Name -Descending | Select-Object -First 1
.\run.cmd --image '.\SD-saliency-900\Source Images\Sc_100.bmp' --params (Join-Path $batch.FullName 'parameters.json')
```

单图模式生成原尺寸二值图 `mask.png` 和六幅分步图组成的 `steps.png`。默认参数针对本数据集的像素尺度选择。

## 算法与实验设计

| 环节 | 操作和原理 |
| --- | --- |
| 直接 Otsu 基线 | 在原图上寻找使类间方差最大的灰度阈值。以外圈约 2.5% 宽度的边框（本数据为 5 像素）估计背景，包含边框灰度中位数的一侧归为背景。缺陷占据大部分边界时，此假设可能失效。 |
| 平滑与背景估计 | 先用 3 × 3 高斯核降低细小灰度波动，再用大窗口对平滑图滤波，估计缓慢变化的背景亮度。 |
| 绝对差分与阈值 | 对平滑图和背景图逐像素取绝对差，亮缺陷和暗缺陷均有响应。在原始灰度差值上使用 Otsu 阈值。分步图第 4 格为了看清弱响应单独拉伸显示灰度。 |
| 形态学与连通域 | 候选闭运算使用 3 × 3 椭圆结构元，先膨胀后腐蚀以连接小间隙。按八邻域统计连通区域，删除面积低于阈值的前景区域。 |

按文件编号排序后，固定随机种子 20261123，从 In、Pa、Sc 各抽 20 张组成开发集。比较背景窗口 31、61，闭运算关闭、开启，连通域最小面积 1、5、15 像素，共 12 组。以 60 张开发图的逐图平均 IoU 选定统一参数。其余每类 280 张共 840 张用于测试。分割函数对全部类别使用同一套参数，无需类别标签。

## 评价和结果文件

IoU = TP / (TP + FP + FN)，精确率 = TP / (TP + FP)，召回率 = TP / (TP + FN)。TP、FP、FN 分别表示正确检出、误检和漏检的前景像素数。汇总时先计算每张图的指标，再作算术平均。若预测和标注皆为空，三项记 1。仅一方为空时，无定义的比率记 0。

| 输出 | 内容 |
| --- | --- |
| `parameters.json`、`parameter_search.csv` | 选定参数、全部候选组合的开发集平均 IoU |
| `masks/baseline`、`masks/difference` | 两种算法各 900 张原尺寸预测掩膜，名称与标注一一对应 |
| `per_image.csv` | 每图每种方法一行，含开发/测试划分、像素计数及三项指标 |
| `summary.csv` | 开发集、测试集及全体数据，按类别和算法汇总。全体 900 张中含 60 张开发图 |
| `cases` | 每类各取测试集 IoU 最接近中位数的样本和最低分样本。图片依次展示原图、平滑、背景、差值、初分割、最终掩膜、人工标注和基线。`index.csv` 可查编号及分数 |

## 本次实验结果

开发集选定 61 × 61 背景窗口、开启闭运算、保留面积至少为 15 像素的连通域。以下结果来自 840 张测试图，保留四位小数。

| 方法 | In 平均 IoU | Pa 平均 IoU | Sc 平均 IoU | 总平均 IoU | 平均精确率 | 平均召回率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 直接 Otsu | 0.0353 | 0.3015 | 0.4657 | 0.2675 | 0.3076 | 0.5577 |
| 背景差分 + Otsu | 0.2768 | 0.1865 | 0.4766 | 0.3133 | 0.4446 | 0.6214 |

- **In** 的提升最大。差分减弱了大范围灰度变化的影响，但局部背景纹理也会被检出。该类平均召回率为 0.8200，精确率为 0.3124。
- **Pa** 的宽暗块在背景图中仍保留明显形状。可查看 `Pa_typical_Pa_295.png`，相减后暗块内部响应较弱，纹理和边缘响应较强，分割区域破碎。
- **Sc** 更能体现误检与漏检的取舍。精确率从 0.5777 升到 0.7428，召回率从 0.8075 降到 0.6199。可查看 `Sc_typical_Sc_98.png`，背景误检减少，但划痕较弱的一端也有漏检。
